# 06.1.01 — Installable CMake package

**Story:** [/docs/roadmap/0006-packaging-and-release/06.1-installable-cmake-package/README.md](/docs/roadmap/0006-packaging-and-release/06.1-installable-cmake-package/README.md)

## Goal

As a downstream developer I want `find_package(entropy)` to work.

## Work

- `install(TARGETS ...)` with export set, `entropyConfig.cmake` and
  `entropyConfigVersion.cmake` generated by `CMakePackageConfigHelpers`.
- Namespaced alias `entropy::entropy`.
- Headers installed under `include/entropy/`.
- Optional: `add_subdirectory` and `FetchContent` consumption documented.

## Success criteria

- A separate example project in `examples/consumer/` builds against the
  installed package in CI.
