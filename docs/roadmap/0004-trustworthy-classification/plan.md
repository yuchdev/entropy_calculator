# 0004 — Trustworthy classification

**Depends on:** 0002-histogram-streaming-api

Purpose: make the "encrypted" verdict defensible. Today compressed archives
and media score above 7.9 and are reported as encrypted or binary depending
only on size. Add the standard statistical battery and format recognition
so the classifier can separate structured, compressed and encrypted data.
